# Dialpad Copilot company context concept

An interactive design prototype with fictional sample data. It is not a released Dialpad feature.

Deploy this directory unchanged to a static web host. For a seeded walkthrough, open the site with `?demo=1` at the end of its URL. The plain URL starts with an empty document library.

Each visitor has a separate browser session. Changes reset on refresh and are not shared with other visitors. The file picker records filenames and selected access scopes in memory; PDF and DOCX bytes are not parsed, stored, or sent to a server. Text pasted into the prototype can be used in its local Test Copilot demo. Content sources and MCPs are mock interfaces.

The `noindex` metadata and `robots.txt` are crawler requests, not access control. Use host-level authentication if the site should be limited to invited reviewers.
